# ✈️ SkyReserve

SkyReserve is a full-stack Airline Reservation System built using **React**, **Spring Boot**, and **PostgreSQL**. The project aims to provide a seamless flight booking experience with secure authentication, flight search, and reservation management.

> 🚧 Currently under development.

## 🚀 Tech Stack

### Frontend
- React.js
- Vite
- React Router DOM
- Axios
- React Icons

### Backend
- Java
- Spring Boot
- Spring Security
- Spring Data JPA

### Database
- PostgreSQL

## ✨ Planned Features

- User Authentication
- Flight Search
- Flight Booking
- Seat Selection
- Booking History
- Admin Dashboard
- JWT Authentication

## ⚙️ Getting Started

### Frontend

```bash
cd frontend/airline-frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
mvn spring-boot:run
```
